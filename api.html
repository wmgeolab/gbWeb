Build an API request

The API returns a JSON object for a single boundary, or a list for queries using ALL. The response includes source information, the year represented, and links to boundary files. Open a download URL to retrieve the geometry.

Use an ISO-3 code, such as USA, KEN, or GBR. Use ALL to query every country.

https://www.geoboundaries.org/api/nightly/gbOpen/USA/ADM1/

Python example

import requests

url = "https://www.geoboundaries.org/api/nightly/gbOpen/USA/ADM1/"
response = requests.get(url, timeout=30)
response.raise_for_status()
boundary = response.json()
print(boundary["gjDownloadURL"])

This example requests one boundary. When using ALL, iterate over the returned list. The nightly endpoint changes as data is updated; use a fixed release for reproducible analysis.

Release types

Release Source & use
gbOpen Recommended for most projects. Open data under CC BY 4.0; attribution required.
gbHumanitarian Mirrored from UN OCHA. Source-specific license terms may be more restrictive; review each file’s metadata.
gbAuthoritative Mirrored from UN SALB and verified through in-country processes. Review source terms, including restrictions on commercial use.

Endpoint format

https://www.geoboundaries.org/api/nightly/[RELEASE]/[ISO-3]/[ADM-LEVEL]/

Levels run from ADM0 (country boundaries) to ADM5 (more local subdivisions). Coverage varies by country. Use ALL in place of the ISO code or level to list available boundaries.

Response fields

Metadata values are generally returned as strings. Optional fields may be empty. Download fields provide links to files; the API response itself contains metadata.

boundaryISO Yes ISO-3166-1 (Alpha 3) code for the country "ALB"
boundaryYearRepresented Yes The year, or range of years in "[START] to [END]" format, which the boundary layers represent "2021" or "1995 to 2021"
boundaryType Yes The type of boundary "ADM1"
boundaryCanonical No The canonical name of a given boundary "Qarqet"
boundarySource Yes A comma-separated list of the primary sources for the boundary "OCHA ROSEA, South African Municipal Demarcation Board"
boundaryLicense Yes The original license that the dataset was released under by the primary source "Creative Commons Attribution 3.0 Intergovernmental Organisations (CC BY 3.0 IGO)"
licenseDetail No Any notes regarding the license. "License was confirmed by two parties and the official website provided in the metadata."
licenseSource Yes The URL of the primary source. "data.humdata.org/dataset/south-africa-admin-level-1-boundaries"

gjDownloadURL Yes The static download link for the geoJSON.
tjDownloadURL Yes The static download link for the topoJSON.
imagePreview Yes The static download link for the automatically rendered PNG of the layer.
