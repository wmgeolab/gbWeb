About geoBoundaries

geoBoundaries is an open database of administrative boundaries maintained by William & Mary geoLab and contributors.

Files use standardized formats and include source, license, and reference-year metadata.

Contributors →

Administrative levels

  • ADM0CountriesThe outer boundary of a country or territory.
  • ADM1First administrative levelStates, provinces, or their local equivalents.
  • ADM2Second administrative levelCounties, districts, or their local equivalents.
  • ADM3+Additional levelsAdditional subdivisions, where data is available.

API access

Retrieve boundary metadata and download URLs over HTTP.

API documentation →
Python exampleGET /api/nightly/ 
import requests

url = "https://www.geoboundaries.org/api/nightly/gbOpen/USA/ADM1/"
boundary = requests.get(url, timeout=30).json()

# Get the GeoJSON download link
print(boundary["gjDownloadURL"])

License & attribution

gbOpen is available under CC BY 4.0. Attribution to geoBoundaries is required.

Other releases have their own terms. Check the source license when using gbHumanitarian or gbAuthoritative data.

Attribution on websites

Place the name “geoBoundaries” and a link to geoboundaries.org prominently on the page that uses the data.

Attribution in apps, films, and other products

Include geoBoundaries in the credits or help menu. If a link cannot be clicked, include the full website address. See the Creative Commons attribution guide for more examples.
